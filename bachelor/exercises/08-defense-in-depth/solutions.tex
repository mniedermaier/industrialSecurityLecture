\begin{taskbox}{Exercise 8.2 -- AppLocker Lab Notes}
Expected log: Event ID 8004 (Exe blocked) and 8007 (Script blocked) under \emph{Applications and Services Logs $\to$ Microsoft $\to$ Windows $\to$ AppLocker}. User receives a Windows toast or explicit denial dialogue.
\end{taskbox}

\begin{taskbox}{Exercise 8.3 -- IDS Lab Notes}
Malcolm dashboards will show: a previously unseen Modbus client IP, write function codes from an unexpected source, and elevated alert count after the injection. Tuning a false positive typically involves whitelisting a known scheduled task or polling interval.
\end{taskbox}

\begin{taskbox}{Exercise 8.4 -- Remote Access (sample)}
Components: vendor laptop $\to$ brokered portal (MFA) $\to$ iDMZ jump host (session recording) $\to$ industrial firewall $\to$ PLC. Operator approval gates each session.
\\
Failure modes:
\begin{itemize}
  \item Vendor MFA token compromised $\to$ jump host still enforces operator approval and session recording.
  \item Operator unavailable $\to$ design must include a back-up approver and a clear escalation; never grant ``standing'' access.
\end{itemize}
\end{taskbox}
