\begin{taskbox}{Exercise 3.2 -- Zones \& Conduits (sample)}
Zones:
\begin{itemize}
  \item Z1 Field (SL-T 2), Z2 Control (SL-T 3), Z3 Supervisory (SL-T 3), Z4 iDMZ (SL-T 2), Z5 IT (SL-T 1).
\end{itemize}
Conduits (excerpt):
\begin{itemize}
  \item C1 Z3$\to$Z4 (Historian replication, OPC UA, push-only, TCP/4840).
  \item C2 Z5$\to$Z4 (Historian read for BI, REST/HTTPS).
  \item C3 Z4$\to$Z3 (vendor jump-host RDP, MFA, time-bound).
\end{itemize}
A data diode is appropriate for C1: it is push-only and integrity of the BPCS must not be at risk from any IT-side compromise. A stateful firewall still depends on software correctness; a diode enforces direction in hardware.
\end{taskbox}
