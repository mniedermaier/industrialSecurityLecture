\labheader

\begin{goalbox}
Bring up the lab Docker stack and confirm that the soft PLC accepts and runs a ladder-logic program. End the lab with a Modbus read working against it.
\end{goalbox}

\begin{stepbox}{1 -- Bring up the stack}
\begin{lstlisting}[language=bash]
cd bachelor/labs
docker compose up -d
docker compose ps           # all services should be (healthy)
\end{lstlisting}
\end{stepbox}

\begin{stepbox}{2 -- Open the OpenPLC web UI}
Browse to \url{http://127.0.0.1:18080}. Log in with the default credentials shown by the OpenPLC project; change the password right away.
\end{stepbox}

\begin{stepbox}{3 -- Upload the ladder program}
Upload the file \texttt{scripts/ladder/conveyor.st}. Click \textbf{Start PLC}. Open the \textbf{Monitoring} page and watch \texttt{Motor} toggle when you flip \texttt{Start}.
\end{stepbox}

\begin{stepbox}{4 -- Read holding registers}
\begin{lstlisting}[language=bash]
docker compose exec student python3 /labs/scripts/modbus_read.py
\end{lstlisting}
You should see ten register values. They will all be zero unless the program has written to them.
\end{stepbox}

\begin{deliverbox}
Hand in: (a) a screenshot of the OpenPLC \emph{Monitoring} page with your running program, and (b) the terminal output of \texttt{modbus\_read.py}.
\end{deliverbox}

\begin{warnbox}
The Modbus listener is bound to \texttt{127.0.0.1:5502} on your host. Do not expose it to your network.
\end{warnbox}
