Helper scripts

All mounted inside the student container at /labs/scripts/.

modbus_read.py

Read 10 holding registers from the OpenPLC over Modbus TCP (FC 0x03).

modbus_inject.py

Write coil 0 = TRUE on the OpenPLC over Modbus TCP – no auth, by design.

modbus_poll_loop.py

Background polling loop – useful as Zeek baseline traffic.

opcua_browse.py

Anonymous OPC UA browse of the open62541 example server's Objects namespace.

mqtt_publish.py

Publish one message to the Mosquitto broker; entry point for the IIoT side-quest.

ladder/conveyor.st

Three-rung Structured Text ladder – the PLC program Lab 02 uploads.

Troubleshooting

The three things that always go wrong.

Connection refused

port 502 closed

OpenPLC's Modbus listener only opens after a program is uploaded and started. Run ./bootstrap-openplc.sh or do Lab 02 step 3 manually.

empty zeek-logs/

Zeek silent

Zeek only sees traffic when the PLC is running and something is talking to it. Generate traffic with modbus_read.py first. If still silent, check docker compose logs zeek for checksum-offload warnings.

login fails

OpenPLC web UI

Defaults are openplc / openplc. If you changed them, set OPLC_USER and OPLC_PASS before running the bootstrap script.
